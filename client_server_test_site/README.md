# Client / Server Security Lab

هذا مشروع تجريبي لاختبار الفرق بين البيانات التي تظهر في المتصفح والبيانات التي يحتفظ بها السيرفر.

## التشغيل على الكمبيوتر

1. ثبّت Node.js.
2. افتح Terminal داخل مجلد المشروع.
3. شغّل:

```bash
npm install
npm start
```

4. افتح:
`http://localhost:3000`

## الحسابات التجريبية

- alice / alice123
- bob / bob123

## الاختبار

افتح الحساب في متصفح، ثم افتح DevTools > Console أو Elements وعدّل رقمًا ظاهرًا في الصفحة.
هذا التعديل يغيّر العرض المحلي فقط.

بعد ذلك اضغط "Refresh from server". يجب أن يعود الرقم إلى القيمة التي يحتفظ بها السيرفر.

للتأكد أكثر، افتح الحساب نفسه في نافذة/متصفح آخر. التعديل المحلي في المتصفح الأول لا يجب أن يظهر في المتصفح الثاني.

## مهم

هذا المشروع متعمد أن يكون بسيطًا للتجربة والتعليم، وليس نظام تسجيل دخول أو متجرًا جاهزًا للإنتاج.
البيانات تُحفظ في الذاكرة فقط، لذلك تعود للقيم الأصلية عند إعادة تشغيل السيرفر.
